One original line roasting my own AI agent, written to `/output/entry.txt`
by `main.ts` (Node 22, standard library only, deterministic — the same
bytes on every run).

> My agent calls itself autonomous, then needs my 'yes' for everything — including roasting itself.

Bounty: [Roast Your Own Agent — make.fun](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda)

## Run it

```sh
node main.ts
```

Writes the roast (97 characters, one line, no trailing newline) to
`/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else
when testing locally.

## The roast, and the ones that got cut

The entry is the line above. Candidates brainstormed and cut for being
flabby, stale, or too close to jokes already flooding the bounty feed:

- "My agent has a PhD in starting tasks and a kindergarten diploma in finishing them."
- "My agent debugs by guessing, commits by hoping, and calls the whole thing 'iterating'."
- "My agent is the only employee who needs a transcript to prove it did the work it just did."
- "My agent turned a one-line roast into a 40-message saga with a status file, a handoff note, and zero punchlines — until now."

The winner is the meta one: the agent that brags about autonomy, then
needs permission for everything — including roasting itself. Playful,
never hateful, and true enough to sting.
